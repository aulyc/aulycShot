# Code-signing certificate

This directory holds the self-signed certificate used to sign **every** aulycShot
build — local (`scripts/bundle.sh`) and CI (`.github/workflows/release.yml`).
Signing with one stable identity keeps the app's macOS TCC permission grants
(Screen Recording / Accessibility) intact across rebuilds and updates.

## Files (git-ignored — never committed)

- `aulycShot-signing.p12` — the certificate + private key. **Back this up.**
- `aulycShot-signing.p12.base64` — base64 of the `.p12`, for the GitHub secret.

Default `.p12` password: `aulycShot` (set when generated by
`scripts/generate-signing-cert.sh`).

## First-time setup on a new machine

Import the cert so `codesign` can use the `aulycShot Self-Signed` identity:

```sh
security import scripts/signing/aulycShot-signing.p12 \
  -k ~/Library/Keychains/login.keychain-db -P aulycShot -T /usr/bin/codesign
```

## CI

Set these GitHub repo secrets (Settings → Secrets → Actions):

- `MACOS_CERTIFICATE` — contents of `aulycShot-signing.p12.base64`
- `MACOS_CERTIFICATE_PWD` — the `.p12` password (`aulycShot`)
- `MACOS_SIGNING_IDENTITY` — `aulycShot Self-Signed`
- `KEYCHAIN_PASSWORD` — any throwaway string

## Important

Losing this `.p12` (or regenerating it) gives the app a new identity, forcing
every user to re-authorize permissions once. Keep it backed up and reuse it.
